# Startup-Funding-Prediction

### Problem Statement: 
Indian Startups search for investors and get thousands of startup funding proposals every year but a small percentage succeeds. Understanding which factor influence startup funding success is crucial for both investors and founders. 

The objective is to analyze historical startup funding data and build ML model that predict funding outcome based on startup attribute.

### Business objective: 
1. Identify key drivers of startup funding.<br>
2. Predict whether the startup will get funding.<br>
3. Estimate expected funding amount.<br>
4. Assist VC's in data driven investment decisions.
